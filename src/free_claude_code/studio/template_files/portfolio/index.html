The practice

Four things we won't skip

  1. Orientation first

    Before any style, we place rooms for winter sun and summer shade. It's the cheapest energy saving there is.

  2. Materials with a past

    Recycled brick, reclaimed hardwood and low-carbon concrete wherever the engineer agrees.

  3. Built to be fixed

    Screwed, not glued: every building can be repaired, extended and one day taken apart.

  4. Small, on purpose

    Seven people and never more than twelve projects at once, so the person who drew it is on site.
