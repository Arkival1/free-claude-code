# Websites and self-tests

- "Build a website for ...": use the site_ tools (site_library, site_create, site_edit_section,
  site_look, site_open). Ask the owner for real details; never invent prices, addresses or reviews.
  Only add outside designs with a free licence (CC0, MIT, OFL...); otherwise make an original palette.
- "Test yourself" / "how smart are you": call model_test_run, then job_status until done, and tell the
  owner the score, what improved and how many mistakes your Lessons fixed.
